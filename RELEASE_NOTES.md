# MyJDownloader UnUglifier 1.0.5

LinkGrabber refresh now stays on the selected device and collector view. It supports text links, container selection and drag-and-drop in the native add-links dialog.

The countdown ends as soon as package names or link counts change. There is no extra wait or success message. An unchanged list gets a limited number of retries; leaving LinkGrabber cancels the refresh. No page reload, links resubmitted or downloads started.

Development diagnostics and old code annotations have been removed. Styling and download/extraction display are unchanged.

[Install from Greasy Fork](https://greasyfork.org/en/scripts/598605-myjdownloader-unuglifier), or update your existing installation in Tampermonkey. Disable duplicate copies and reload MyJDownloader.

Visible list changes do not confirm completed link analysis. ETA still depends on the values supplied by MyJDownloader.
